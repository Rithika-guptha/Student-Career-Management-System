# Student Career Management System (SCMS)

## About the Project
This is a beginner-friendly Python project designed to manage student details and career information.

## Features
- Add student details
- View student records
- Check placement eligibility
- Search for students

## Technologies Used
- Python

## Python Concepts Used
- Variables and data types
- Input and output
- Conditional statements
- Loops
- Lists and dictionaries

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python scms.py

- Save student records permanently.
